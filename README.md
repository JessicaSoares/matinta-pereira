# Matinta Pereira

Primeira proposta de site em português para o game. HTML e CSS, sem dependências de build. Abra `index.html` no navegador ou sirva a pasta com `python3 -m http.server 8080`.

O conteúdo é conceitual: não declara plataformas, data de lançamento ou funcionalidades confirmadas. As ilustrações abstratas são feitas em CSS. As fontes do Google Fonts usam fontes locais de fallback quando não há conexão.

Antes da publicação, substituir os textos conceituais pelas informações oficiais do jogo e adicionar materiais e canais reais da equipe.
